# GameFleet – notes for AI assistants and contributors

Self-hosted dashboard for game servers: a FastAPI backend (`backend/src/gamefleet_backend`) queries each server with its
native protocol, a SvelteKit SPA (`frontend/src`) shows status, players and per-game details. The README covers setup,
configuration, layout and make targets; this file holds only what is not obvious from the code.

## Decisions to keep

- Schema changes are idempotent SQL in `LEGACY_SCHEMA_UPGRADES` (`db/session.py`). Alembic has no versions and never
  runs; do not add migrations. `game` is `VARCHAR(50)`, so new game types need no DB change.
- `GameServerPublic.from_server` validates from attributes: rows hold `game` as text and `model_dump()` output caused
  Pydantic serializer warnings.
- Live info is a discriminated union on `kind` (`models/server_info.py`). Game-specific fields go into a `*ServerInfo`
  subclass; the frontend narrows on `kind`.
- `frontend/src/lib/api/Api.ts` is generated by `make swagger`. Never edit it; regenerate and commit it whenever API
  models change.
- The frontend is a static SPA (`adapter-static`); links use `resolve()` from `$app/paths`. Tailwind v4 is configured in
  `app.css`; there is no `tailwind.config.js`.
- Auth is a stateless HMAC bearer token kept in localStorage (frontend and API are different origins). `/api/games`
  stays public so `<img>` can load artwork.
- The backend container uses host networking and mounts the Docker socket. Docker-linked servers are keyed by container
  name (compose recreates ids). `detect()` order is labels > `IMAGE_CATALOG` > keywords > unique default port; only
  label and image matches auto-import. Deleting a docker server records its name in `ignoredcontainer`.
- Host stats are request-driven and cached (10 s for `stats`, 5 min for `du`); CPU% needs two samples, so the first
  request reports null. No background stats loop.
- Backups/rollback are planned on top of `data_path`, `world_path` and `ContainerMount`; keep those fields populated.
- All configuration comes from the root `.env` (loaded once in `gamefleet_backend/__init__.py`; containers get it from
  compose). The backend builds its database URL from `DB_*`; `DATABASE_URL` is an override, there is no second env file.
- Prettier is not applied repo-wide. Do not reformat files you are not otherwise changing.

## Adding a game

Follow the README steps, plus: popular Docker images go into `IMAGE_CATALOG` and a keyword into `KEYWORDS`
(`models/container_catalog.py`); a new `kind` also needs `CAPABILITIES`, `overviewTiles` and `serverProperties` in
`frontend/src/lib/gameinfo.ts`.

## Versioning

One version in `backend/pyproject.toml` and `frontend/package.json` (currently 0.6.1). Bump it in the same commit as a
user-visible change: patch for fixes and dependency updates, minor for features or UI changes, major for breaking API or
DB changes. Docs and tooling commits need no bump. Run `uv lock` after touching `pyproject.toml`; commit both lockfiles.

## Toolchain pins (September 2026)

- TypeScript stays on 6.x; svelte-check and typescript-eslint do not accept 7 yet.
- Node 24 LTS and Python 3.14 in the images; switch to Node 26 when it becomes LTS (October 2026). uv is pinned in
  `backend/Dockerfile`; keep it at the local `uv --version`.
- `python-dotenv` is unpinned via `[tool.uv] override-dependencies`: `satisfactory-api-client` pins `~=1.0.1` but never
  imports it.

## Verifying

Run `make check` and `cd frontend && pnpm build` before declaring work done; report failures verbatim.

Backend smoke test: `cd backend && GAMEFLEET_USERS=admin:secret uv run uvicorn gamefleet_backend.main:app --port 8010`,
log in via `POST /api/auth/login`, then call `/api/servers`, `/api/servers/live-info`, `/api/docker/discovered` and
`/api/servers/host-stats` with the bearer token. The dev database comes from `make db`; the frontend targets the spare
backend with `GAMEFLEET_API_URL=http://localhost:8010 pnpm dev --port 3010`.

Screenshots: `brave --headless=new --disable-gpu --no-sandbox --hide-scrollbars --window-size=1440,1100
--virtual-time-budget=60000 --screenshot=out.png "http://localhost:3000/main?theme=light"` (`?theme=` is a deliberate
override in `app.html`). Pages behind the login need puppeteer-core driving Brave through the login form.

## Protocol testing notes

- Public Minecraft, Bedrock, 7 Days to Die, TF2 and Garry's Mod servers answer their queries. A local
  `factoriotools/factorio:stable` container (RCON password in `/factorio/config/rconpw`) covers Factorio.
- ARK: SA official servers resolve through ARK's CDN server lists plus the EOS `sessions/{id}` endpoint
  (`matchmaking/filter` returns 403); private ASA servers need RCON. Official ASE hosts do not answer A2S.
- Satisfactory is untested against a live server: no public API server is reachable and `steamcmd +login anonymous`
  no longer downloads the dedicated server.
- BattleMetrics needs a paid plan and the Steam master server hostname no longer resolves; do not build on either.
